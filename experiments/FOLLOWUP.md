# 可复现的本地实验

`npm run experiments` 使用公开的合成样例运行静态规范化及规则检查，保存 `reports/experiments.json`；没有 API 调用。需要私人日志的实验必须显式传入 `--trace`，见 README。

静态解析仅恢复支持的字面量调用形式，绝不执行日志代码。未知语法、输出数量不匹配及未知副作用保持未知。单元测试覆盖恢复、等待结果时间位置、证据失效及重复验证行为。

历史开发期阈值探索和真实会话报告不包含在公开副本，不能作为当前实现的可复现准确率结果。默认阈值仍为暂定值；合理重复需要具体理由与证据，仅有 verify 标签不足。

真实标注尚未完成独立复核。下一步应按 REAL_EVALUATION.md 获取独立盲审、真实正例与留出任务，再评估阈值和干预策略。
